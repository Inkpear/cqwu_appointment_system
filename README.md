# 重庆文理学院场所预约平台

本项目是为重庆文理学院师生提供的场所预约与管理系统。项目后端使用 Spring Boot 框架开发，提供 API 服务。

## 项目核心功能

后端目前已实现以下业务模块：

### 1. 场所管理 (Venue Management)
- 支持对场所的基础信息（名称、位置、容量、设备、每日开放时间）进行管理。
- 支持对场所进行分类。
- 实现了双重状态机制：
  - **基础状态**: 由管理员设置，表示场所的基本可用性（如 `AVAILABLE`, `MAINTENANCE`）。
  - **实时状态**: 由定时任务每分钟计算并更新，表示场所的即时状态（如 `OCCUPIED`, `CLOSED`）。
- 支持为每个场所配置独立的业务规则（如是否需要审批、单次预约最大时长）。
- 提供场所信息的增、删、改（单体/批量）、查（分页/筛选）API。

### 2. 调度核心 (Scheduling Core)
- 采用“时间块 (`TimeBlock`)”模型记录所有对场所时间的最终占用。
- 提供时间冲突检测服务，供上层业务调用。

### 3. 预约工作流 (Reservation Workflow)
- 支持预约申请的完整生命周期管理，包含 `PENDING`, `CONFIRMED`, `IN_PROGRESS`, `COMPLETED`, `REJECTED`, `CANCELLED`, `EXPIRED` 等状态。
- 实现审批机制：
  - **自动审批**: 对于无需审批的场所，定时任务会自动处理待审批 (`PENDING`) 的申请。采用“先到先得”的竞争机制，按申请时间顺序处理冲突。
  - **人工审批**: 提供 API 供管理员手动批准或拒绝申请。批准时会进行最终的时间冲突检查。
- 成功的预约会生成唯一的“预约码”用于查询。
- 实现了基于用户角色和所有权（自己/他人）的权限校验。

### 4. 数据同步 (Data Synchronization)
- 提供专门的 API 用于与外部系统（如教务系统）同步课程数据。
- 同步接口支持强制批量插入课程安排，并能自动拒绝与现有用户预约冲突的记录。
- 提供批量清空指定场所课程数据的功能。

### 5. 安全框架 (Security)
- **认证**: 基于 JWT 的双令牌（Access Token + Refresh Token）认证。
- **授权**: 使用 Spring Security 和 `@PreAuthorize` 注解进行方法级权限控制。
- **输入校验**: 使用 Jakarta Bean Validation (`@Valid`) 及自定义注解对 API 输入进行校验。
- **异常处理**: 使用 `@RestControllerAdvice` 实现全局异常处理。

## 技术栈 (Backend)

- **核心框架**: Spring Boot
- **持久层**: MyBatis
- **数据库**: MySQL
- **认证/授权**: Spring Security, JWT
- **分页**: PageHelper
- **定时任务**: Spring Scheduling

## 后续工作

- **数据可视化**: 开发统计分析接口，为前端报表提供数据。
- **消息推送**: 实现预约状态变更的实时消息通知。
- **CAS 对接**: 集成学校统一身份认证系统。
