# 重庆文理学院场所预约平台

本项目旨在为重庆文理学院师生提供一个便捷、高效、智能的在线场所预约与管理工具。

## 系统核心功能

### 1. 场所管理：动态、精细、全面的资源掌控

- **场所信息全景**: 管理员可以对场所的各类信息进行全面维护，包括基础的名称、位置、容量，也包括设备配置、每日的固定开放与关闭时间等。
- **分类与规则**:
  - **分类管理**: 可将场所划分为“普通教室”、“多媒体会议室”、“重点实验室”等不同类别。
  - **准入规则**: 可以为**每一类**场所设定独立的准入规则。例如，可以配置“重点实验室”只允许特定类型的用户（如教师）提交预约申请。
  - **预约策略**: 支持为**每一个**场所独立配置业务策略，如“是否需要人工审批”、“单次预约的最长时长限制”等。
- **智能双重状态**:
  - **基础状态**: 管理员可以设定场所的“基础”状态，如将某个教室设为“维修中”，这将作为最高优先级，临时禁止所有预约。
  - **实时状态**: 系统通过一个**自动化调度引擎**，每分钟都在后台计算每个场所的**即时状态**。它能准确地反映出某个场所在“此时此刻”是“空闲可用”、“正在占用”还是“已关闭”，为用户提供最准确的实时信息。

### 2. 预约流程：公平、严谨、人性化的工作流

- **完整的生命周期**: 一次预约申请会经历一套完整的状态流转，从“待审批”到“已确认”，再到“进行中”，最终归档为“已完成”，每一个环节都清晰可追溯。
- **智能审批机制**:
  - **自动审批**: 对于普通场所，系统会自动处理预约申请。为了保证公平，它采用“先到先得”的竞争机制。当多个申请竞争同一时间段时，系统会按**申请提交的先后顺序**进行处理，自动批准最先提交的申请，并以“时间冲突”为由自动拒绝后续的冲突申请。
  - **人工审批**: 对于需要人工管理的特殊场所，申请会进入管理员的审批队列。管理员在批准时，系统会**再次进行时间冲突检查**，确保在审批的这一刻，该时间段没有被其他活动占用，从而保证审批操作的有效性。
- **人性化的沟通**:
  - **申请事由**: 用户在提交申请时，不仅可以填写简短的标题，还可以附上详细的“申请事由”，供管理员审批时参考。
  - **审批意见**: 管理员在操作时，可以填写“审批意见”。无论是批准时留下“请注意保持卫生”的嘱托，还是拒绝时给出“与期末考试安排冲突”的明确原因，都将清晰地传达给申请人。

### 3. 日程与调度：统一、可视化的时间管理

- **统一调度核心**: 系统的底层将所有对时间的占用——无论是**教务系统的固定课程**，还是**师生提交的预约**，或是**管理员设置的维修时段**——都视为统一的“时间占用事件”。
- **可视化日历**: 为前端提供强大的日历数据接口。用户可以在一个直观的日历视图上，清晰地看到某个场所每天、每周、每月的完整日程安排，一目了然地找到空闲时间。

### 4. 系统级功能：安全、可靠的管理与同步

- **用户与权限**: 实现了完整的用户角色管理体系，严格区分普通用户和多级管理员的访问与操作权限。
- **数据同步**: 提供专门的、受最高权限保护的接口，用于与学校的教务系统等外部平台进行数据同步。在导入新学期的课程表时，系统能够**自动处理**与现有学生预约的冲突，确保教务安排的最高优先级。
